# Waze Chat Plus — Stickers

Sticker packs for [Waze Chat Plus](https://greasyfork.org/scripts/599275), the userscript that improves the Waze chat. Free and
made by the community.

- **Official packs:** the Waze moods, installed for everyone who has Waze Chat Plus (`packs/`; coming soon).
- **Make your own pack:** a folder of WebP images and a `wcp-stickers.json` in any public GitHub repository. Read
  [docs/sticker-packs.md](docs/sticker-packs.md) (Quick start in ten minutes) and check it with `tools/validate.mjs`.
- **Report a pack or a sticker:** from its menu in the chat (Report), or open an issue here.

Status: in development (not published yet).
